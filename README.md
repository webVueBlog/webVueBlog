## 👋 关于我

我是 **哪吒（Jeskson）**，一名全栈架构师，长期专注于 **IoT、SaaS、微服务、高并发系统与 AI 应用工程化**。

我擅长从业务目标出发，完成产品从 **0 到 1 的架构设计、研发交付与持续演进**，并将技术能力转化为可衡量的业务成果。

| 🏗️ 从 0 到 1 | ⚡ 大规模系统 | 💰 商业化实践 |

| IoT、SaaS、电商与 AI 平台 | 百万级用户与设备、高并发数据处理 | 亿级营收系统建设与长期演进 |
